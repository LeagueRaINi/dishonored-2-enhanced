## Current state (2026-10-17)

Direction: replace individual passes of the original D3D11 renderer from the in-process
module `void-inject` (PLAN.md P1/P2/G1-G3). Native D3D11 only, no DXVK (user).

- **P1 baseline:** native, two eotw scenes (E051, docs/performance-baseline.md); CPU-bound.
- **P2 CPU path:** driver has no D3D11 command lists (E052); engine scheduler A/B pending.
- **G1 FSR 4:** bindings (E053), engine-level TAA replacement native + upscale, jitter,
  mip bias, OIT masks (E054, docs/fsr4-integration.md); run in game (E057, E058, E060).
- **G2 lighting:** options study (docs/lighting-options.md); cvar overrides with
  `image_anisotropy 16` (E055); own AO in place of HBAO+ (default, E063/E064); sun contact
  shadows (`contact_shadows`, default on since the user's in-game check, E066); shadow
  submission patch (E062).
- **G3 texture mods:** `OpenFileRead` substitution (E056, docs/texture-replacement.md),
  tooling and hook implemented; not run in game.
- **Tooling:** in-game egui overlay (F2; docs/overlay.md), live settings with save, patch
  registry (`patches.rs`, `patch.<id>`; boot-video skip migrated); offline-verified only.
- **Removed 2026-10-17** (cleanup authorised by the user): Bevy viewer (`void-viewer`),
  `void-sim`, `void-compare`, the in-process full-scene renderer/takeover (`r3`, `gpu`,
  `takeover`, `ocean`, `fftwaves`, `assets`, `snapshot`), `tools/hktag.py`, `tools/rx003/`.
  Evidence rows E001-E050 and the historical docs (renderer-replacement.md,
  m2-materials.md, m3-*.md, experiments/, formats/) still name those tools as their
  reproduction method.
- **Commit hashes** in the docs and code comments (e.g. checkpoint 9282529, cleanup 190c284,
  "build 46faa27") come from the private development history before the public release.
  The published history does not contain them.
